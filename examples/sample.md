# Hebbian Learning

## Summary
Hebbian learning is an unsupervised learning principle used in neural networks. It is based on the statement "Neurons that fire together, wire together". The weight change is Δw_{i} = η x_{i} y.

- A connection grows stronger when input and output are active together.
- With w_{1} = 0.2 and Δw_{1} = 0.2 the new weight is 0.4.
