# Changelog

All notable changes to this skill are listed here. Versions follow
[Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-21

### Added
- Handwriting renderer with per-letter variation, plain and ruled paper, black
  or blue ink, and an optional pencil border.
- Input from Word (`.docx`), typed PDF, plain text and Markdown files.
- `Doc` class for maths, tables, stacked fractions and boxed results.
- Support for a custom handwriting font through `--font`.
- Bundled Mali and Playpen Sans fonts (SIL Open Font License).
